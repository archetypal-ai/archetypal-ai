# Contributing to Archetypal AI

Thank you for your interest in Archetypal AI.

## How to Contribute

### Bug Reports

Open a [Bug Report](https://github.com/archetypal-ai/archetypal/issues/new?template=bug_report.yml)
with your version, OS, steps to reproduce, and any error output.

### Feature Requests

Open a [Feature Request](https://github.com/archetypal-ai/archetypal/issues/new?template=feature_request.yml)
describing the use case and why it matters.

### Documentation

Documentation improvements are always welcome. Edit the relevant `.md` files
and open a pull request.

### Install Scripts

The `install/` directory contains platform installers. If you find an issue
with installation on your platform, PRs are appreciated.

## Development

The Archetypal AI CLI source code is maintained in a private repository.
This public repository contains:

- Install scripts (`install/`)
- Documentation (README, docs)
- Issue tracking and community discussion
- Release artifacts and changelogs

If you're interested in contributing to the core CLI, reach out to us at
contributors@archetypal.ai.

## Code of Conduct

Be respectful. We're building a civilization, not tearing one down.

- No harassment, discrimination, or personal attacks
- Constructive feedback only
- Assume good intent
- Help newcomers
